# Cartan Geometry Research

Research repository for ongoing work on Cartan geometry, parabolic geometry,
logarithmic geometry, branched geometry, and positive-characteristic analogues.

## Main files

- `CLAUDE.md` — instructions for Claude Code
- `main.tex` — master LaTeX document
- `preamble.tex` — packages and theorem environments
- `references.bib` — bibliography
- `notes/overview.tex` — overall research status
- `notes/definitions.tex` — definitions and notation
- `notes/results.tex` — established results only
- `notes/examples.tex` — examples and test cases
- `notes/questions.tex` — open problems and gaps
- `notes/daily/` — chronological research diary
